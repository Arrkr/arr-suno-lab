# ARR Sound Lab 업데이트 안내

ARR Sound Lab Windows 앱의 업데이트 버전 안내를 위한 폴더입니다.
기존 ARR SUNO LAB 페이지와 독립적으로 사용합니다.

- 현재 기준 버전: 5.3.0
- 앱을 켤 때 자동으로 연결하지 않습니다. 사용자가 업데이트 확인을 눌렀을 때만 확인합니다.
- `stable.json`은 제작자 서명으로 검증하는 버전 안내입니다.
- 전체 프로그램, 개인 작업물, 글꼴 파일, 분석 모델, 비밀 서명 키는 이 저장소에 올리지 않습니다.
- `.arrupdate`는 현재 버전에 맞는 변경 파일만 담습니다. 사용자는 앱에서 직접 선택할 수 있습니다.
- 구매자용 파일은 판매처를 통해 전달합니다. 현재 공개 업데이트 다운로드는 제공하지 않습니다.
- 복구는 직전 업데이트에서 교체한 앱 파일만 되돌립니다. 작업물과 글꼴은 유지합니다.

이 폴더가 생성되었다는 사실은 유료 판매 개시 또는 판매용 라이선스 검토 완료를 의미하지 않습니다.
